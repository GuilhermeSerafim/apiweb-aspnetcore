# ScreenSound — estudo em C#

Repositório de estudos da Alura associado à trilha de criação de APIs em C#. O código disponível nesta versão é um projeto de console em .NET 8.

## Estado do código

- `ScreenSound/ScreenSound.csproj` define um executável com destino `net8.0`.
- O trecho ativo de `ScreenSound/Program.cs` cria um dicionário com dois artistas e percorre seus itens no console.
- O arquivo também preserva, comentado, um fluxo anterior de menu.
- A solução mantém modelos de artistas/músicas e arquivos de menus como material de estudo.

Esta versão não contém um projeto web separado; o ponto de entrada não define endpoints HTTP nem configura Swagger. O nome do repositório e o contexto do curso não devem ser interpretados como uma API pronta.
